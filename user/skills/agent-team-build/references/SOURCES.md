# Sources for team-refs

Compared against the kit's `agent-team-build` skill (`SKILL.md`, `orchestrated.md`, templates) and `rules/agent-teams.md`. Only what the kit lacked was written, in our own words. All four sources are MIT, Jesse Vincent (superpowers 7.0.0). No source file was run or installed; the helper scripts were read as data only.

## Conflicts with kit rules (kit rule wins)

1. rule:outward-acts: merge, push, PR creation and branch deletion in finishing-a-development-branch.
2. rule:patterns-and-dispatch: parallel code-writing agents on one tree (dispatching-parallel-agents); findings through files (subagent-driven-development).
3. `agent-team-build`: serial-only implementers, 5 fix rounds, lead never fixes (subagent-driven-development).
4. `orchestrated.md` fixed classes: `cd` into a worktree.

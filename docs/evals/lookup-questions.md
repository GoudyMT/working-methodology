# Lookup test for `kit.mjs find`

Ten "where is the rule on X?" questions, typed as a person would, not copied from the rule text. A hit is the
expected section among find's top 3 results. Bar: 8 of 10; 2 or more misses reopen the search choice. The
expected sections are named by their 0.7.0 headings; Phase 1 adds the IDs.

| # | Query (typed as written) | Expected section |
|---|---|---|
| 1 | how should commit messages look | Commit Message Format |
| 2 | what goes in the handoff before compacting | Handoff Message Structure |
| 3 | how long can the session log get | Tracking File Size Caps (Hard Limits) |
| 4 | someone typed a wrong code into a lock screen | Design for Human Error |
| 5 | can I paste the rules into an agent's brief | Kit Standards (How the Methodology Improves) |
| 6 | test the preview link before merging | Preview Test Before Merge |
| 7 | is it ok to change a test so it passes | Test Integrity (Tests Never Yield to Implementation) |
| 8 | the numbers from my script look too good | Enumerate Before You Count |
| 9 | what should I call my branch | Branching |
| 10 | the bundle is over budget | Size Budgets: Trim Before You Ask |

The testing rules live in the standards; this file points to them.

- Strict test-first; what a deferral covers -> rule:tdd
- Tests never yield to the implementation -> rule:test-integrity
- Test value and proof by break -> rule:test-value
- Realistic shared fixtures, forced failure paths -> rule:tdd
- Separated test teams for foundation logic -> rule:tdd
- Contrast gated on the rendered pair -> rule:visual-design-collaboration
- Structure, not appearance, in component tests -> rule:loop-workflow-mode

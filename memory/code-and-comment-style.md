The code rules live in the standards (and the global standards they extend); this file points to them.

- Self-contained comments, no cycle labels -> _Working Standards.md "Code Standards"
- Comment depth, docstrings, constants -> _Working Standards.md "Code Standards"
- Comment labels reworded to the mechanism -> _Working Standards.md "Pre-Compact Scan"
- ASCII only, special characters at run time -> _Working Standards.md "Code Standards"
- Comment out, prove, then delete -> _Working Standards.md "Code Standards"
- Literal regexes, existing patterns, display transforms -> _Working Standards.md "Code Standards"

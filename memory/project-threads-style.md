description: Read when working in the owner's AI project workspace or threads - how replies, questions, updates and memory are shaped there.

  type: feedback

- **Lead with the answer.** The first line says the result or the recommendation.
- **One plain question per decision.** One short line per option, then a recommendation. Do not stack several decisions in one question.
- **Plain short sentences, no em dashes.** Use commas, colons, periods or ` - `.
- **Every milestone goes out as a visible message.** In a thread, plain assistant text may never reach the owner; only a posted reply (and the status checklist) does. Post a short reply when an agent's result is integrated, a fix lands, or a decision is needed. Why: the owner judges progress from what lands in the thread; unseen work reads as a stall.
- **Say a wait aloud.** When a turn ends waiting on agents or a job, say so in the reply or the checklist.
- **Memory is one file per subject**, a line or two per fact (the rule and its reason, not the story), each file kept under 3 KB, with a one-line index entry per file.

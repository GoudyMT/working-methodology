# Worker Brief Template

> One job for a cloud worker, sent through the kit's worker runner (rule:where-work-runs). A job not on the list stays on the owner's PC.

```md
- **Job:** <one of: tests, builds, gate checks, research, read-only review>
- **Branch:** <the owner's own feature branch>
- **Do:** <the one task, with its files or question>
- **Done when:** <the command and the result that proves it>
- **Hand back:** <results, failures and files changed, in the final message>
```
